# SpendWise – Student Expense Tracker

SpendWise is a simple web-based expense tracker designed specifically for college students. It helps users record their daily expenses, manage their monthly budget, and understand their spending habits through an easy-to-use dashboard.

## Features

* Add, edit, and delete expenses
* Categorize daily expenses
* Set and track monthly budgets
* View total and remaining budget
* Analyze spending through charts
* Filter and search expenses
* View monthly spending summaries

## Tech Stack

* React
* Tailwind CSS
* Python
* FastAPI
* SQLite / PostgreSQL

## Purpose

The project aims to provide students with a simple and effective way to manage their personal expenses and make better financial decisions.
